## 3. Deskripsi Layanan

Finara adalah aplikasi **pencatatan dan pengelolaan keuangan pribadi/keluarga** dengan pendekatan *local-first*: data utama dapat disimpan di perangkat Anda. Setelah login, Layanan dapat menyinkronkan data ke server kami agar tersedia di perangkat lain dan mendukung **workspace bersama** (undangan anggota, peran seperti pemilik, anggota, atau pengamat).

Fitur dapat berubah seiring pembaruan Aplikasi (termasuk pembaruan over-the-air jika build production memakai Shorebird). Kami berupaya menjaga ketersediaan Layanan, tetapi **tidak menjamin** Layanan bebas gangguan, tanpa error, atau selalu tersedia.

## 6. Mode tamu dan sinkronisasi

- Tanpa login, Konten Pengguna dapat disimpan **hanya di perangkat**. Kehilangan perangkat atau penghapusan data Aplikasi dapat **menghapus permanen** data tamu jika tidak dicadangkan oleh Anda sendiri.
- Login dan/atau persetujuan fitur cadangan/sinkronisasi (sesuai alur di Aplikasi) dapat mengunggah atau menyelaraskan data ke server kami.
- Anda memahami bahwa sinkronisasi bergantung pada koneksi internet, versi Aplikasi, dan kebijakan workspace.

---

## 7. Workspace bersama dan peran

1. Pemilik atau pengelola workspace dapat **mengundang** anggota dan menetapkan peran (misalnya dapat mencatat transaksi atau **hanya melihat** sebagai pengamat).
2. Anggota workspace bersama dapat **melihat** data keuangan workspace sesuai peran yang diberikan. Jangan bergabung ke workspace jika Anda tidak percaya pemilik atau anggota lain.
3. Anda tidak boleh membagikan undangan atau akses workspace untuk tujuan melanggar hukum, spam, atau penyalahgunaan.
4. Fitur workspace bersama lanjutan dapat memerlukan **Finara Premium** atau masa trial; batas fitur ditampilkan di Aplikasi.
